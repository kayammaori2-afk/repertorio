# Changelog

## 0.1.0 — 2026-11-16

First public release of Repertorio under MIT.

- Persistent SQLite profiles, transactional migration, revision-aware corrections and idempotent writes.
- Official-SDK MCP server: stdio and authenticated loopback Streamable HTTP.
- Deterministic selection from 16 original mappings, with familiarity/spoiler constraints and fallback.
- Versioned JSON import/export, CSV repertoire, readable summaries and confirmed scoped deletion.
- Real two-process demo and observed Claude Code → Codex continuity.
- Reproducible selector benchmark, preserved negative results and artificial pilot analysis.
- English README, Portuguese quickstart/session instruction, host configurations and security policy.

See [verification](docs/verification.md) and [release verification](docs/publication.md). Human learning benefits and remote ChatGPT interoperability are not claimed.
